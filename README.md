# 防災リスクマップ（bousai-map）

日本の主な天災リスクと飲食チェーンの分布を、レイヤーのオン/オフで日本地図に重ねて俯瞰できる
単一HTMLのPWA。**公開URL: https://nobumitsu-3141.github.io/bousai-map/**

- レイヤー: 活断層地震（Sランク37断層・30年確率・M別めやす円）/ 海溝型地震（10領域）/
  津波（沿岸概況）/ 火山（常時観測31）/ 台風・高潮 / 豪雨・土砂 / 豪雪（県別3段階）/
  県庁所在地（47市）/ 100万都市（12市区）/ 主要都市（各県2〜8市・約160市。ズームで表示が増える）/
  飲食チェーン11社の都道府県別店舗数（複数同時選択・ドット分布/県別濃淡の2モード）
- 地図タップで詳細（断層のM・確率、都市の人口、県の概況、チェーン店舗数）
- ピンチ（2本指）/ホイール/ダブルタップでズーム、ドラッグで移動。スケールバー・設定の自動保存つき。
  iPhoneはSafariで開いて「ホーム画面に追加」→オフラインでも動作。
  ページ本体はネットワーク優先のため、オンラインならリロードするだけで最新版になる
- 地震データは政府・地震調査研究推進本部の長期評価（算定基準日2026年1月1日）。
  チェーン店舗数は各社公式・集計サイトのWeb調査値（概数・時点はアプリ内「出典・注意」参照）
- **概算のめやすであり公式ハザードマップの代替ではない。** 住所単位は
  [J-SHIS](https://www.j-shis.bosai.go.jp/) / [重ねるハザードマップ](https://disaportal.gsi.go.jp/) で確認

## 開発メモ

- 原本・生成スクリプト・分析文書は非公開リポジトリ `bousai`（`tools/app_template.html` → `build_app.py` で
  `index.html` を再生成し、ここへコピーして公開）
- 中身を更新したら `sw.js` の `CACHE = 'bousai-map-vN'` の N を必ず上げる（iPhoneのキャッシュ更新）
